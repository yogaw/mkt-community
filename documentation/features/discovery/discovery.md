# Discovery

Epic covering content discovery across types. The MVP scope is basic title search; the shared `Category` taxonomy is documented inside Video Library (videos) and News (news) — Announcements do not use categories.

| Feature | Latest Version | Status | Spec |
|---------|----------------|--------|------|
| Search | v0 | Feature Spec / Draft | [search/search-v0.md](./search/search-v0.md) |

**Deferred to later versions:** full-text/body search, fuzzy matching, autocomplete/suggestions, category filtering on search results.
