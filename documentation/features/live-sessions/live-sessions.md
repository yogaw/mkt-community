# Live Sessions

Epic covering scheduled live sessions. For MVP the platform does not host streaming — sessions redirect to external platforms (Zoom / Google Meet). The MVP scope is the member-facing read path (next upcoming session); creation and management belong to the Admin epic.

| Feature | Latest Version | Status | Spec |

| Upcoming Live Session | v0 | Feature Spec / Draft | [upcoming-live-session/upcoming-live-session-v0.md](./upcoming-live-session/upcoming-live-session-v0.md) |

**Deferred to later versions / Admin epic:** session create/edit/delete UI, RSVP/registration, calendar export, reminders, past-session archive.
